The '''vanilla-net''' branch is an in-development branch of Chocolate Doom to add support for vanilla Doom's networking protocols. This will allow Chocolate Doom and vanilla Doom to play netgames together.

The branch adds the following features:

* [[IPX protocol support]]
* [[Serial protocol support]]
