[[Image:Chocorenderlimits.png|thumb|The Chocorenderlimits port showing the visplane borders of E1M1 of Doom.]]

Chocorenderlimits was a fork of Chocolate Doom that adds an on-screen display that shows information about the Vanilla Doom rendering limits. Along with information, visual indicators appear to show which areas are not able to render or crash the game. This is intended to assist level authors in creating levels for Vanilla Doom, by identifying areas of the levels that will crash the game.

The port was first published in February 2011 by GhostlyDeath for the benefit of Sarah Mancuso (esselfortium)'s upcoming project ''Knee Deep In Knee Deep In ZDoom''.

Unlike like GhostlyDeath's other port, [[Strawberry_Doom|Strawberry Doom]], the official upload for this port has now been removed, so the only way to run it on your computer is via alternative downloads, because of this, of the downloads that you find may not have a README file
