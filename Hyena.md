**Hyena** is a Doom TC featuring a storyline set in the distant future. To play under Chocolate Doom:

1.  Download {% include Idgames.md file="levels/doom/Ports/megawads/hyena.zip" title="Hyena TC" %}.
2.  Extract the .zip containing the game files.
3.  Run with the following command line parameters:

<!-- -->

    chocolate-doom -iwad doom.wad -merge Hyena.wad -deh HYENA.DEH

**NOTE:** If your Doom IWAD isn\'t located in the current directory, you might need to provide the full path.
