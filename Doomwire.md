Doomwire is a multiplayer lobby program for Chocolate Doom created by Russell Rice. It was created as an alternative to DoomServ a few years after it was shut down.

Originally designed for [[doom:ZDoom|ZDoom]], it has now been reoriented around Chocolate Doom because of the author's craving for oldschool deathmatch and cooperative play.

You can help test Doomwire by downloading the latest version along with the latest unofficial Chocolate Doom Windows build at the official website.
