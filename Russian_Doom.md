Russian Doom is aimed to full and proper Russian translation of Doom, Heretic and Hexen games, as well as its setup executable and online help. Additionally it has numerous vanilla bug fixes, enhanced 640x400 display resolution, improved game palettes, removed limits and offers many optional aesthetic game enhancements. 

The project is based on [[Chocolate Doom]] and [[Crispy Doom]].

== Supported games ==

The following games are supported:

* DOOM Press Release Beta
* DOOM Shareware
* DOOM 1
* The Ultimate DOOM
* DOOM II: Hell on Earth
* DOOM II: No Rest for the Living
* Master Levels for Doom II
* Final DOOM: TNT Evilution
* Final DOOM: The Plutonia Experiment
* Freedoom: Phase 1
* Freedoom: Phase 2
* FreeDM
* Heretic Shareware (Beta)
* Heretic Shareware
* Heretic
* Heretic: Shadows of the Serpent Riders
* Hexen Shareware
* Hexen
* Hexen: Deathkings of the Dark Citadel

No need to use “<tt>-file</tt>” for loading translated resources, the port will automatically load them depending on the game you are playing. However, due to port specifics and language differences, it is recommended to only play the original game series.

Press Beta is available "from the box" with command line parameter “<tt>-beta</tt>”, no need to download anything.

== Game enhancements ==

Russian Doom offers many different visual enhancements like colored blood, transparency, mouse look and brightmaps. They can be switched in the ex-compatibility section of the Setup executable, as well as in configuration files.

All features are available for Doom, many features are available for Heretic, and just few are available for Hexen.

Besides, there is also available “<tt>-vanilla</tt>” command line parameter, which will disable all enhancements without any changes in configuration file, making the game visual appearance as close as possible to original executables.
