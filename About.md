Most modern [[Doom:Category:Source ports|Doom ports]] aim to improve the game in various different ways - adding new features, fixing bugs and limits etc. However, there are a number of reasons that having a copy of the original executables is useful:

* [[Demo compatibility]] - the majority of demos are recorded for the original DOS Doom 1.9. Few ports maintain demo compatibility. Compet-N only accepts demos recorded under the original executables.
* For testing purposes. Releasing a WAD "for [[Doom:Vanilla Doom|Vanilla Doom]]" means that it will work on all ports.
* Some players dislike the changes made by ports and prefer to play under the original executables. 

The original executables do not run properly under modern Operating Systems (Windows XP, Linux, etc). Chocolate Doom aims to reproduce the original executables as closely as possible, providing a modern port of the source code while providing backwards compatibility.

Chocolate Doom aims for [[compatibility]] with:

* v1.9 demos
* v1.9 savegames
* v1.9 configuration file
* v1.9 bugs (including VPO, etc)
* [[Dehacked]] mods
