Obituary is a [[TC]] by The Innocent Crew.  

Loading Obituary is unusual because it uses NWT rather than DEUSF.  To play Obituary:

* [http://www.doomworld.com/idgames/index.php?id=2021 Download] the Obituary TC and extract it.
* Run with these command line parameters:

 chocolate-doom -deh obtic1.deh -nwtmerge obtic2.wad -file obtic1.wad obtic2.wad

(Currently, you must use the latest version from Subversion to do this.
