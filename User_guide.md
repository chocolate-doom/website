== Multiplayer ==

Chocolate Doom can be played online and includes enhanced network code compared to the original engine.
* For basic instructions, see the [[Multiplayer]] page.
* The Lobby-driven Multiplayer client [[Doomwire|Doomwire]] allows you to find other players to play against.
* [http://master.chocolate-doom.org/ The master server] tracks active Chocolate Doom servers.
* [http://doomseeker.drdteam.org/ Doomseeker] also supports Chocolate Doom.

== Online assistance == 

You can get help online from several sources:

* [irc://irc.oftc.net/chocolate-doom #chocolate-doom] is an IRC channel with Chocolate Doom users knowledgeable about the port. IRC web chat is available [https://webchat.oftc.net// here].
* The Doomworld forums contain a long-running [http://www.doomworld.com/vb/source-ports/34164-chocolate-doom discussion thread] about the port.  The forums contain many experts on the subject who may be able to answer your questions.
* Contact the author [mailto:fraggle@remove-this-bit-to-email-me.soulsphere.org by email].

== Bugs ==

If you discover a bug, please [https://github.com/chocolate-doom/chocolate-doom/issues submit a bug report].  However, some bugs are actually intended behavior. See the NOT-BUGS file that was included in your download (viewable [https://github.com/chocolate-doom/chocolate-doom/blob/master/NOT-BUGS here]).
