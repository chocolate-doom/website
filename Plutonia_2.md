'''[[Doom:Plutonia 2|Plutonia 2]]''' is a 32-level megawad for [[Doom:The Plutonia Experiment|The Plutonia Experiment]].  Unlike most other megawads, this ''requires'' a copy of Final Doom to run (or [http://www.nongnu.org/freedoom/ Freedoom]<sup>*</sup>):
# [http://lsvc.free.fr/Plutonia2/pl2.zip Download Plutonia 2], and extract it
# Run with the following options:
 chocolate-doom -iwad plutonia.wad -file PL2.WAD -deh PL2.DEH

<sup>*</sup>Freedoom gained support for Plutonia WADs after the 0.6.3 release, so you'll either need to build it from the current git tree or download a [http://free.doomers.org/ nightly build]

==Issues==
MAP23 of the WAD includes a mapping error, which often causes Chocolate Doom to crash when playing the level and when viewing the Plutonia 2 demoloop. Consult the [[FAQ#Why does Plutonia 2 crash in MAP23 and during the first demo?|FAQ]] for the available workarounds.
