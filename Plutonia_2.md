**[Plutonia 2](https://doomwiki.org/wiki/Plutonia_2)** is a 32-level megawad for [The Plutonia Experiment](https://doomwiki.org/wiki/The_Plutonia_Experiment). Unlike most other megawads, this *requires* a copy of Final Doom to run (or [Freedoom](/Freedoom.md)):

1.  Download {% include Idgames.md file="levels/doom2/megawads/pl2.zip" title="Plutonia 2" %} and extract it.
2.  Run with the following options:

<!-- -->

    chocolate-doom -iwad plutonia.wad -file PL2.WAD -deh PL2.DEH

## Issues

MAP23 of the WAD includes a mapping error, which often causes Chocolate Doom to crash when playing the level and when viewing the Plutonia 2 demoloop. Consult the [FAQ](/FAQ.md#Why_does_Plutonia_2_crash_in_MAP23_and_during_the_first_demo?) for the available workarounds.
