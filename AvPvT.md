To play **AvPvT** under Chocolate Doom:

1.  Download {% include Idgames.md file="themes/apt/avpvt2.zip" title="AvPvT" %}.

3.  Run with the following command line parameters:

    chocolate-doom -merge AvPvT2.wad -deh AvPvT2.deh
