== The great categorisation project ==

The Chocolate Doom wiki has accumulated quite a lot of screenshots now, and it would be nice to categorise them.  I've started doing this but it needs more work.

Firstly, all screenshots should be categorised by game type; attach one of the following templates depending on the game depicted: [[Template:Doom screenshot]], [[Template:Heretic screenshot]], [[Template:Hexen screenshot]], [[Template:Chex Quest screenshot]]. This is only necessary for images that show the game itself in progress. Some existing screenshots mistakenly use [[Template:Screenshots]].

Next, screenshots should be categorised by purpose: [[:Category:Platform screenshots]] (for screenshots showing Chocolate Doom running on different OS/CPU platforms), [[:Category:WAD screenshots]] (for screenshots showing Chocolate Doom playing various different WADs/TCs), [[:Category:Textscreen screenshots]] and [[:Category:Setup tool screenshots]] (for screenshots showing various features of libtextscreen and chocolate-setup, respectively) and [[:Category:Feature screenshots]] for screenshots intended to demonstrate some particular feature of Chocolate Doom. 

Not all screenshots are in the Screenshots category, so it's useful to use [[Special:Imagelist]] to get a full list of images.  Eventually, the "Category:Screenshots" part should be removed from the Screenshot template, and ideally there should be no images directly classified under [[:Category:Screenshots]]; it should just be a super-category for all the other categories.
