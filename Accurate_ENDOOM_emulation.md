Whenever you exit out of Doom in DOS, a screen called [https://doomwiki.org/wiki/ENDOOM ENDOOM] is shown, this is a colorful pop-up that usually says who made the [https://www.chocolate-doom.org/wiki/index.php/Category:WADs WAD] that can also have information such as the web address of the person who made the mod, an example of this can be seen on the right. Many WADs modify the ENDOOM screen in interesting and artistic ways.

Today, many modern source ports of Doom will have the option to show this screen turned off by default, however, not only will Chocolate Doom have this fetcher turned ''on'' by default, but Chocolate Doom ensures that this feature is not lost by having an accurate emulation of the DOS text mode display in order that the ENDOOM screen can be displayed.

ENDOOM display is implemented in a cross-platform way, so ENDOOM screens are shown correctly on all Operating Systems and platforms.
