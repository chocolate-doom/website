**Doom Retro** is a fork of Chocolate Doom with enhancements from other Doom source ports that aims for a \"classic, refined Doom source port\". The port, that was made for the Windows OS, saw its first release on 2013-12-10 by Brad Harding to coincide with Doom\'s 20th anniversary.

Unlike Chocolate Doom, that can be said to be a more conservative port, Doom Retro adds features that were not seen in the original release of Doom in 1993 nor its Chocolate counterpart. Some of the new features and enhancements that it adds are;

- Removing the original [static limits](https://doomwiki.org/wiki/Static_limits) of the game.
- Adding more blood and gore sprites.
- Changing the cacodemon and Hell knight\'s blood to blue and green respectfully
- Randomly mirrored corpses.
- Several hundred level-specific fixes are applied to repair problems such as missing or incorrect textures, stuck monsters, etc.
- Support for [vanilla](https://doomwiki.org/wiki/Doom_engine#Vanilla_Doom), [limit removing](https://doomwiki.org/wiki/Limit_removing), and [Boom](https://doomwiki.org/wiki/Boom) compatible WAD files.
- Plus more that can be found on [The Doomwiki](https://doomwiki.org/wiki/Doom_Retro).

One of the downsides to using this port is that currently, it only supports singleplayer and not [multiplayer](https://www.chocolate-doom.org/wiki/index.php/Multiplayer), along with this, in order to freely implement certain features, and due to the nature of them, [Doom demo](https://doomwiki.org/wiki/Demo) recordings and playback has been disabled.
