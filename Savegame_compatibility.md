Starting with version 0.1.3, Chocolate Doom features full '''savegame compatibility''' with [[Doom:Vanilla Doom|Vanilla Doom]].  Old DOS savegames will now load in Chocolate Doom.  Chocolate Doom itself saves to the Vanilla Doom savegame format, so you can load Chocolate Doom savegames in Vanilla Doom.

The new savegame code is implemented in a way which is architecture-independent, so you can (theoretically) even load DOS savegames from [[Wikipedia:endianness|big-endian]] and [[Wikipedia:64-bit|64-bit]] machines.
