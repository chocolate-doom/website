These are instructions on how to play the **Aliens Doom 3 - Aliens versus Predator TC** (Beta 0.7) under Chocolate Doom.

1.  Obtain a copy of {% include Idgames.md file="themes/aliens/aliendm3/ad3beta7.zip" title="the TC" %}.
2.  Download **ad3beta7.zip** from one of the mirror sites.
3.  Extract the zip archive.
4.  Run with the following [command-line arguments](/Command-line_arguments.md):

<!-- -->

    chocolate-doom -iwad doom.wad -deh ad3.deh -merge ad3spfl.wad ad3gfx.wad ad3snd.wad ad3mus.wad ad3lev.wad

You should rename \"-iwad doom.wad\" to \"-iwad doomu.wad\" if you\'re using [The Ultimate Doom](https://doomwiki.org/wiki/The_Ultimate_Doom), and to \"-iwad freedoom1.wad\" if you\'re using [Freedoom](/Freedoom.md).
