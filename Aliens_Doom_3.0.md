These are instructions on how to play [[doom:Aliens Doom 3 (Beta 0.7) TC|Aliens Doom 3 (Beta 0.7) TC]] under Chocolate Doom.

# Obtain a copy of the [http://www.doomworld.com/idgames/index.php?id=5739 Ultimate Doom version] of the Aliens Doom 3 (Beta 0.7) TC.
# Extract the zip archive. 
# Run with the following [[command-line arguments]]:

 chocolate-doom -deh ad3.deh -merge ad3spfl.wad ad3spfl.wad -file ad3gfx.wad ad3snd.wad ad3mus.wad ad3lev.wad
