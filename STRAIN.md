STRAIN is a 32-level TC by the Alpha Dog Alliance.

Following are instructions for running STRAIN under Chocolate Doom:

1.  Download {% include Idgames.md file="levels/doom2/megawads/strain.zip" title="STRAIN" %} from idgames.
2.  Extract the .zip containing the game files.
3.  Run with the following command line:

<!-- -->

    chocolate-doom -deh STRAIN.DEH -merge STRAIN.WAD
