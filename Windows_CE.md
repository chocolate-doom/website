'''Windows CE''' (also known as '''Windows Mobile''', '''Pocket PC''', and '''Windows Embedded Compact''', among other names) is a now-defunct embedded operating system originally developed by Microsoft in the late '90s.

Originally targeting handheld devices ([[wikipedia:Palmtop PC|palmtops]]), the OS was also used for a number of embedded applications since it implemented a subset of the [[wikipedia:Windows API|win32 API]] while being able to run on machines with a much smaller footprint.

== Running Chocolate Doom on Windows CE ==

Older versions of Chocolate Doom were ported to Windows CE, but support has since been removed. To install, download the .cab file for v1.3.0:

* [https://www.chocolate-doom.org/downloads/1.3.0/chocolate-doom-1.3.0-wince.cab chocolate-doom-1.3.0-wince.cab]

There is only an ARM binary. For other CPUs you might want to try [[doom:Doom for Pocket PC|Doom for Pocket PC]] or [[doom:CellDoom|CellDoom]].

You'll also need to copy an [[doom:IWAD#IWAD_files|IWAD file]] onto the device in order to play. The easiest thing to do is to download [https://www.doomworld.com/idgames/idstuff/doom/win95/doom95 Doom95 shareware] and extract DOOM1.WAD from the .zip.
