The following are instructions on how to play [[doom:Hacx|HACX]] under Chocolate Doom.

# First, make sure you have Doom II 1.9 in a location Chocolate Doom can use it.
# Obtain a copy of HACX.  This can be found [http://www.doomworld.com/idgames/index.php?id=14031 here] for free download.
# Extract hacx.wad and hacx.deh from the zip.  (Use "unzip -L" to convert the upper-case names to lower-case automatically).
# Run with the following commmand-line options:

 chocolate-doom -merge hacx.wad -deh hacx.deh
