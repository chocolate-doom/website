The following are instructions on how to play [[doom:Hacx|HACX]] under Chocolate Doom.

# First, obtain a copy of HACX.  This can be found [http://www.doomworld.com/idgames/index.php?id=14030 here] for free download.
# Extract the zip and run the installer.  This is a DOS based program.  If you do not have a functional version of DOS which can run this, try running it under [http://dosbox.sourceforge.net/ DOSBox]. 
# You will need to provide the path to your Doom II install directory.
# After the installer has completed, you will have a file named '''hacx.wad'''.  There is also a dehacked file '''hacx.deh''' included in the downloaded zip.
# Run with the following commmand-line options:


 chocolate-doom -merge hacx.wad -deh hacx.deh
