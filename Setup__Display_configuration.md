[[File:Configure Display.png|thumb|right|300px]]
After selecting '''Configure Display''' from the main menu, another window should open that lets you configure some basic settings. The ability to control whether the game runs in full screen is here, which when checked, will display the game on the entire screen and your usual desktop and other applications are not visible.

Screen mode lists resolutions available to use. If full screen is enabled, there may be anywhere from a single resolution to many multiples of them available, depending on your display drivers and operating system. If full screen is disabled, it will list out some common resolutions up to the full size of your desktop, normally displaying [[Wikipedia:Aspect ratio (image)#4:3 standard|4:3 aspect ratio]] resolutions.

== Advanced ==
[[File:Configure Display (Advanced).png|thumb|right|300px]]
''Advanced display options'' are also available. The first option of which allows you to toggle the preservation of the 4:3 aspect ratio, by ensuring that the game's pixels are slightly taller than they are wide. Doom renders to a 320x200 display buffer, but almost all monitors in the 1990s were of the 4:3 aspect ratio, and this caused the final display to retain a more square display than a wide one. Turning this off on modern systems will cause the game to appear stretched horizontally. Seee [[Doom:Aspect ratio|aspect ratio]] on the Doom Wiki for more details.

You may also toggle the display of [[Doom:ENDOOM|ENDOOM]] from this window. This is a screen that normally was displayed on DOS after quitting the game, and some WADs include their own replacement graphics for it. Chocolate Doom emulates this screen using [[libtextscreen]], the same text-mode emulation that the setup program itself uses.

On some operating systems and compilation configurations, there is a third option here, the capability of saving screenshots to [[Wikipedia:Portable Network Graphics|PNG]] files instead of the [[Wikipedia:PCX|PCX]] format that Doom originally used. The PCX format is largely obsolete and few applications implement support for it. Due to an extra dependency on libpng, this option is not available in the standard Windows versions of Chocolate Doom.
