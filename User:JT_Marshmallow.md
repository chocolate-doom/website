= Marshmallow Doom =

Marshmallow Doom is a gameplay-oriented source port which infuses a classic Doom experience with many sweet new features such as: multiplayer bots, dynamic gameplay-driven music, treasure items, player inventory, and many more.

== Synopsis ==

Marshmallow Doom is a fork of the wonderful [[Crispy Doom]] source port which provides many beautiful new enhancements such as high-resolution, colored HUD text, removal of static engine limits, translucency, free vertical looking, jumping, and more.  Marshmallow Doom is unlike most source ports in that it does not make any changes to system-oriented code (renderer, sound, networking, etc.) but also does not add any new assets (sprites, sounds, music, etc.) to the game.
