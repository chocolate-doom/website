First released in 1996, '''Eternal Doom''' is a 32-level megawad, originally being developed by Team Eternal, later being acquired and worked on by [https://doomwiki.org/wiki/TeamTNT TeamTNT], who earlier that year would publish the TNT: Evilution as apart of Final Doom.

{{idgames|file=themes/TeamTNT/eternal/eternal.zip|title=Once you have downloaded the ZIP file for the wad from the /idgames Archive}}, it may become overwhelming to know what to do next as there are numerous files in the ZIP, but luckily, running the WAD is quite simple.

To play Eternal Doom under Chocolate Doom, simply follow these steps:

# If you have not yet done so, download {{idgames|file=themes/TeamTNT/eternal/eternal.zip|title=Eternal Doom}}
# Extract the .zip containing the game files.
# Run with the following command line options:

 chocolate-doom -merge eternall.wad
