First released in 1996, **Eternal Doom** is a 32-level megawad, originally being developed by Team Eternal, later being acquired and worked on by [TeamTNT](https://doomwiki.org/wiki/TeamTNT), who earlier that year would publish the TNT: Evilution as apart of Final Doom.

{% include Idgames.md file="themes/TeamTNT/eternal/eternal.zip" title="Once you have downloaded the ZIP file for the wad from the /idgames Archive" %}, it may become overwhelming to know what to do next as there are numerous files in the ZIP, but luckily, running the WAD is quite simple.

To play Eternal Doom under Chocolate Doom, simply follow these steps:

1.  If you have not yet done so, download {% include Idgames.md file="themes/TeamTNT/eternal/eternal.zip" title="Eternal Doom" %}
2.  Extract the .zip containing the game files.
3.  Run with the following command line options:

<!-- -->

    chocolate-doom -merge eternall.wad
