The [[wikipedia:Mac OS X|Mac OS X]] version of Chocolate Doom includes a minimalist launcher program for selecting the IWAD files to use and starting the game.  The purpose of this is to make installation of Chocolate Doom on OS X straightforward and congruent with the rest of the operating system.

A brief list of features:
* The source port is packaged as a .DMG archive, and Chocolate Doom can be installed simply by dragging the "Chocolate Doom" icon into the Applications folder.
* The locations of the IWAD files for various games can be configured.
* Extra command line parameters can be entered.
* Launching of PWADs and dehacked patches is straightforward, as the launcher includes file associations for .WAD and .DEH files.  Double clicking on a PWAD in the Finder configures the appropriate command line parameters to load the game with the PWAD.
* The [[setup]] tool can be accessed from a button in the launcher window.
* "Command Prompt" menu option allows a terminal window to be opened which is preconfigured with environment variables to allow the game to be started.
