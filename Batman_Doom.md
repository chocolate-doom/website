The following are instructions on how to play [[doom:Batman Doom|Batman Doom]] under Chocolate Doom.

# First, download [http://www.doomworld.com/idgames/index.php?id=12391 batman.zip] containing the game files.
# Run with the following options:
 chocolate-doom -merge batman.wad -deh batman.deh
