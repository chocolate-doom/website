The following are instructions on how to play [[doom:Batman Doom|Batman Doom]] under Chocolate Doom.

# First, download [http://www.doomworld.com/idgames/index.php?id=12391 batman.zip] containing the game files, and extract it.
# Download [http://www.doomworld.com/idgames/index.php?id=14658 vbatman.zip], the Vanilla Batman Doom fix, and extract it.
# Run with the following options:
 chocolate-doom -merge batman.wad -deh batman.deh vbatman.deh
