Even if you are not a programmer, you can help out by contributing to the Chocolate Doom website. Every page on this website can be edited to fix errors and add new information.

To edit a page, send a pull request to [the Github repository for the website](https://github.com/chocolate-doom/website). You'll need to create a Github account if you don't already have one. Github have [some instructions](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request) about how to create a pull request if you've never done it before. If you're a frequent committer, you'll be granted permission to edit the pages directly without the need for the pull request step.

Text for the pages on this website is written in [Markdown](https://en.wikipedia.org/wiki/Markdown). This mostly looks like plain text, with some special syntax for adding formatting. [There's a cheat sheet here](https://www.markdownguide.org/cheat-sheet/) with a summary.

## TC instructions {#tc_instructions}

One aim of this site is to add instructions on how to play [TCs](/Category:TCs.md) under Chocolate Doom. You can help by adding pages for TCs which have not yet been documented.

Include a screenshot of the TC on the page. Please run Chocolate Doom in windowed mode, and take a screenshot so that the title bar is visible; this demonstrates that the TC is running in Chocolate Doom.

A list of well-known TCs can be found [here](https://doomwiki.org/wiki/List_of_WADs). Be sure to only try those listed as \"Vanilla Doom\" in the \"Engine\" column.

## Old screenshots {#old_screenshots}

The wiki has a fair number of screenshots, but some of them are now out of date and don\'t accurately show current versions of Chocolate Doom. You can help update [Old screenshots](/Category:Old_screenshots.md) by replacing them with new ones (see the page for information on how to take screenshots).

## Other information {#other_information}

If you know of anything missing from the website, feel free to add it. Do not be afraid to make any change you feel will improve the site, no matter how [bold](https://en.wikipedia.org/wiki/Wikipedia:Be_bold_in_updating_pages).

## History

For many years, the Chocolate Doom website used to be a wiki based on [MediaWiki](https://en.wikipedia.org/wiki/MediaWiki), the same software that powers Wikipedia ([here's a snapshot](https://web.archive.org/web/20060225231459/http://www.chocolate-doom.org/wiki/index.php/Chocolate_Doom) of what the website looked like back in 2006). The website today is no longer based on MediaWiki, although it still retains the look and feel, as the stylesheet was reused for the new site.

In 2026, the wiki was converted to Markdown format and moved onto Github Pages for hosting. The database from the old site was converted into Git history, so the full 20 year history of the website has been preserved. The new site is based on [Jekyll](https://en.wikipedia.org/wiki/Jekyll_(software)), with some custom templates and plugins to reproduce some of MediaWiki's functionality.

There were various motivating factors for moving off MediaWiki: the main concern was the maintenance burden of running a MediaWiki website, including dealing with upgrades and having to deal with security issues. Contributions to the website have dropped off sharply in recent years, possibly in part due to anti-spam measures that we had to put in place; it's hoped that moving onto Github makes the site more accessible to contributors again.
