International Doom, formally called Russian Doom, is aimed at full and proper Russian translation of Doom, Heretic and Hexen games, as well as its setup executable and online help. Additionally, it has numerous vanilla bug fixes, enhanced 640x400 display resolution, improved game palettes, removed limits and offers many optional aesthetic game enhancements. 

Language choosing between English and Russian is available in the game options menu, as well as in the Setup executable.

The project is based on [[Chocolate Doom]] and [[Crispy Doom]], with additions from [[Doom Retro]].

== Supported games ==

The following games are supported:

* DOOM ([[doom:Press_Release_Beta|Press Release Beta]], shareware, registered, [[doom:The_Ultimate_Doom|The Ultimate Doom]])
* [[doom:Doom_II|Doom II]]
** [[doom:No_Rest_for_the_Living|No Rest for the Living]]
** [[doom:Master_Levels_for_Doom_II|Master Levels for Doom II]]
* [[doom:Final_Doom|Final Doom]]
* [[doom:SIGIL|SIGIL]]
* [[doom:Atari_Jaguar|Atari Jaguar]] (as a recreation)
* [[doom:Freedoom|Freedoom]] (Phase 1 and 2, FreeDM)
* [[doom:Heretic|Heretic]] (shareware beta, shareware, commercial, Shadow of the Serpent Riders)
* [[doom:Hexen|Hexen]] (shareware, commercial, [[doom:Hexen:_Deathkings_of_the_Dark_Citadel|Hexen: Deathkings of the Dark Citadel]])

Press Beta is available with command line parameter “<tt>-beta</tt>”, and translation of Doom for Atari Jaguar is available as a total conversion with command line parameter “<tt>-jaguar</tt>”. Both games are available "from the box", no need to download anything.

== Gameplay enhancements ==

International Doom offers many different visual enhancements like colored blood, transparency, mouselook and brightmaps. All of them can be toggled in the Gameplay options menu. 

Most of the features are available for Doom, many features are available for Heretic, and just a few are available for Hexen.

Besides, there is also an available “<tt>-vanilla</tt>” command line parameter, which will disable all enhancements without any changes in the configuration file, making the game visual appearance as close as possible to original executables.
