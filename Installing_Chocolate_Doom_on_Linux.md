'''Installing Chocolate Doom on Linux''' is usually a matter of using your Linux distribution's package manager. Most popular Linux distributions have a Chocolate Doom install package.

The Chocolate Doom project does not distribute Linux binaries ([[FAQ#Why_do_you_not_distribute_Linux_binaries?|see here for why]]).

== Linux distributions ==

'''[https://pkgs.alpinelinux.org/packages?name=chocolate-doom Alpine Linux]''': <code>sudo apk add chocolate-doom</code>

'''[https://aur.archlinux.org/packages/chocolate-doom/ Arch Linux]''': <code>yay -S chocolate-doom</code>

'''[https://packages.debian.org/stable/chocolate-doom Debian / Ubuntu]''': <code>apt install chocolate-doom</code>

: Note that in releases of Debian before v9, you must enable the ''contrib'' area to access the package.

'''[https://admin.fedoraproject.org/pkgdb/package/rpms/chocolate-doom/ Fedora]''': <code>dnf install chocolate-doom</code>

'''Gentoo''': See [[Building Chocolate Doom on Gentoo]].

'''Guix System''': <code>guix install chocolate-doom</code>

'''[https://community.linuxmint.com/software/view/chocolate-doom Linux Mint]''': <code>sudo apt install chocolate-doom</code>

'''[https://madb.mageia.org/package/show/name/chocolate-doom Mageia]''': <code>urpmi chocolate-doom</code>

'''[https://software.opensuse.org/package/chocolate-doom OpenSuSE]''': <code>zypper install chocolate-doom</code>

'''[https://github.com/void-linux/void-packages/tree/master/srcpkgs/chocolate-doom Void Linux]''': <code>sudo xbps-install chocolate-doom</code>

== BSD ==

'''[https://www.freshports.org/games/chocolate-doom FreeBSD]''': <code>pkg install chocolate-doom</code>

'''[http://ports.su/games/chocolate-doom OpenBSD]''': <code>pkg_add chocolate-doom</code>

'''[https://pkgsrc.se/games/chocolate-doom NetBSD]''': <code>pkg_add chocolate-doom</code>

'''[https://github.com/DragonFlyBSD/DPorts/tree/master/games/chocolate-doom DragonFlyBSD]''': <code>pkg install chocolate-doom</code>
