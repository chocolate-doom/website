**Installing Chocolate Doom on Linux** is usually a matter of using your Linux distribution\'s package manager. Most popular Linux distributions have a Chocolate Doom install package.

The Chocolate Doom project does not distribute Linux binaries ([see here for why](/FAQ.md#Why_do_you_not_distribute_Linux_binaries?)).

## Linux distributions {#linux_distributions}

**[Alpine Linux](https://pkgs.alpinelinux.org/packages?name=chocolate-doom)**: `sudo apk add chocolate-doom`

**[Arch Linux](https://aur.archlinux.org/packages/chocolate-doom/)**: `yay -S chocolate-doom`

**[Debian / Ubuntu](https://packages.debian.org/stable/chocolate-doom)**: `apt install chocolate-doom`

: Note that in releases of Debian before v9, you must enable the *contrib* area to access the package.

**[Fedora](https://admin.fedoraproject.org/pkgdb/package/rpms/chocolate-doom/)**: `dnf install chocolate-doom`

**Gentoo**: See [Building Chocolate Doom on Gentoo](/Building_Chocolate_Doom_on_Gentoo.md).

**Guix System**: `guix install chocolate-doom`

**[Linux Mint](https://community.linuxmint.com/software/view/chocolate-doom)**: `sudo apt install chocolate-doom`

**[Mageia](https://madb.mageia.org/package/show/name/chocolate-doom)**: `urpmi chocolate-doom`

**[OpenSuSE](https://software.opensuse.org/package/chocolate-doom)**: `zypper install chocolate-doom`

**[Void Linux](https://github.com/void-linux/void-packages/tree/master/srcpkgs/chocolate-doom)**: `sudo xbps-install chocolate-doom`

## BSD

**[FreeBSD](https://www.freshports.org/games/chocolate-doom)**: `pkg install chocolate-doom`

**[OpenBSD](http://ports.su/games/chocolate-doom)**: `pkg_add chocolate-doom`

**[NetBSD](https://pkgsrc.se/games/chocolate-doom)**: `pkg_add chocolate-doom`

**[DragonFlyBSD](https://github.com/DragonFlyBSD/DPorts/tree/master/games/chocolate-doom)**: `pkg install chocolate-doom`
