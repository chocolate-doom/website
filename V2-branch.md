'''v2-branch''' is a source code [[branch]] to develop version 2.0 of Chocolate Doom. It continues the work started on [[raven-branch]] and [[strife-branch]], which are now obsolete.

The v2 branch is complete and can be downloaded via the main [[Downloads|download page]]
