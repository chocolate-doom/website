'''v2-branch''' was a source code [[branch]] that developed version 2.0 of Chocolate Doom. It continued the work started on [[raven-branch]] and [[strife-branch]].

v2-branch is now complete and Chocolate Doom v2.0 can be downloaded via the main [[Downloads|download page]]
