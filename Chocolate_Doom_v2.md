[[File:V2-branch_9_games.png|thumb|right|Demonstration of Chocolate Doom v2: nine Doom engine-based games running simultaneously]]
Chocolate Doom version 2 is now in beta. You can help out by testing the beta and [https://sourceforge.net/p/chocolate-doom/bugs/ reporting bugs] that you encounter.

The biggest change with version 2 is the addition of support for Heretic, Hexen and Strife in addition to Doom. See [https://sourceforge.net/p/chocolate-doom/code/HEAD/tree/tags/chocolate-doom-2.0.0-beta1/NEWS the NEWS file] for more information.

All of the downloads below are GPG-signed. See the [https://soulsphere.org/projects/chocolate-doom/2.0.0-beta1/ downloads directory] for the .asc format detached signatures.

== Windows binaries ==

Downloads can be found here:
* [https://soulsphere.org/projects/chocolate-doom/2.0.0-beta1/chocolate-doom-2.0.0-beta1-win32.zip Chocolate Doom v2.0.0-beta1]
* [https://soulsphere.org/projects/chocolate-doom/2.0.0-beta1/chocolate-heretic-2.0.0-beta1-win32.zip Chocolate Heretic v2.0.0-beta1]
* [https://soulsphere.org/projects/chocolate-doom/2.0.0-beta1/chocolate-hexen-2.0.0-beta1-win32.zip Chocolate Hexen v2.0.0-beta1]
