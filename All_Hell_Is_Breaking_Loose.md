The following are instructions on how to play All Hell is Breaking Loose under Chocolate Doom.

1.  First, download {% include Idgames.md file="levels/doom2/a-c/allhell.zip" title="All Hell is Breaking Loose" %} from the idgames archive.
2.  Extract the .zip file containing the game files.
3.  Run with the following options:

<!-- -->

    chocolate-doom -merge allhell.wad ahflats.wad -file ahlevels.wad ahmus.wad -deh allhell.deh
