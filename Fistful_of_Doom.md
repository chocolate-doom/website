'''Fistful of Doom''' is a wild west themed Doom TC. To play under Chocolate Doom:

# Download {{idgames|file=levels/doom2/d-f/fistful3.zip|title=Fistful of Doom}}.
# Extract the .zip containing the game files.
# Run with the following command line parameters:

 chocolate-doom -merge fistful.wad -file fistfix.wad
