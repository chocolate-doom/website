**Project Infinity** is a fork of the Chocolate Doom codebase. It aims to be a new school port adding new levels of modability to Doom, although not much work had been done on the port.

The project has not been worked on since around 2013, making it fairly certain that it will no longer see any updates. To further this, the GitHub page for the port no longer exists, meaning there is no way to officially download the port. [ Cass Python](/User:OwlMan.md) for sometime did try and track down a download for the port, but was unsuccessful. Python finally [E-Mailed the head dev of the port](https://owlman.neocities.org/spam/other/project_infinity_code.html) asking if they had a copy of it, however, this was also unsuccessful, as they no longer had a copy of it, effectively meaning that the port is now lost.
