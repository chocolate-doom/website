This template is used to draw the boxes which link somewhere else.  Parameters are:
; link= : The link target for the icon 
; image= : File to use as the icon.
; text= : Text to show next to the icon.
; imgsize= : Size of the image (default 48px)
; clear= : Clear left, right or both (default both)

For example:

 <nowiki>{{Linksbox|link=Chocolate Doom|image=File:Chocolate-doom.png|text=Chocolate Doom!}}</nowiki>

gives

{{Linksbox|link=Chocolate Doom|image=File:Chocolate-doom.png|text=Chocolate Doom!}}

</noinclude>
