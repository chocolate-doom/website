Screenshots in this category are old and need to be replaced by better screenshots. In particular, screenshots should follow the following rules:

- Running in windowed mode, and displaying the title bar.
- At least 640x480 dimensions.
- Aspect ratio correction turned on.
- Screenshots demonstrating TCs/WADs should only show the window and title bar, not the surrounding desktop environment.
- Screenshots demonstrating an OS/platform should show the full desktop environment, along with something that shows the Operating System and version ([:File:Chocolatent351.png](/File:Chocolatent351.png.md) is a good example).
