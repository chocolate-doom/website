Chocolate Doom is under active development and aims for a roughly three month release cycle. If you\'re a fan you might want to keep up to date with the latest bleeding edge pre-release version [from the Git repository](https://github.com/chocolate-doom/chocolate-doom).

You can browse the Chocolate Doom source code [here](https://github.com/chocolate-doom/chocolate-doom). Github has [a page](https://github.com/chocolate-doom/chocolate-doom/commits/master) that shows recent commits.

## Forks and branches {#forks_and_branches}

Major Chocolate Doom features are developed on separate branches and merged to trunk when complete. There is a list of branches [here](/Category:Branches.md). For now the active ones are:

- [vanilla-net](/Vanilla-net.md) - Branch adding back support for the vanilla networking protocols.

Chocolate Doom is designed to be easily forked so that people can develop their own modified versions if they wish. There is a list of forks [here](/Category:Forks.md).

## How to help out {#how_to_help_out}

There are many ways to help out the project:

- [Submit a bug report](https://github.com/chocolate-doom/chocolate-doom/issues) if you find a problem. Feature requests are also welcome as long as they are within the scope of the project.
- If you\'re a programmer, you\'re welcome to submit patches / send pull requests.
- [Contribute](/Contributing_to_the_Website.md) to the Website!
