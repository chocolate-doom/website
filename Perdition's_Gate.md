'''[[Doom:Perdition's Gate|Perdition's Gate]]''' is a commercial 32-level add-on that was originally slated to be a third megawad included in [[Doom:Final Doom|Final Doom]]. For more information about its development, visit [http://www.mustaine.com/about/video-game-work/perditions-gate/ Tom Mustaine's website].

==Demo==
An eleven level demo of the wad can be downloaded freely.
# [http://www.gamefront.com/files/perdgatezip/;845721;/fileinfo.html Download the demo] and extract it.
# Run with the following options:
 chocolate-doom -merge PG-LTD.WAD

==Full version==
The full version of the wad originally came on a CD-ROM with a DOS-based installer, but the installer does not have to be used.
# Insert the CD-ROM and navigate to the PG directory.
# Copy the file PG-RAW-X.WAD to your hard disk. Additionally, if you wish to watch the opening demos, you can also copy PGDEMO19.WAD.
# Run with the following options:
 chocolate-doom -file PG-RAW-X.WAD PGDEMO19.WAD
Note that the DOS installer renames PG-RAW-X.WAD to PERDGATE.WAD when choosing a minimal install, so you may wish to do the same.
