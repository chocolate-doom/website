Building Chocolate Doom on Linux is fairly straightforward. However, the process for doing so depends on the Linux distribution that you are using.

Here are some instructions for building under common distributions:

- [Building Chocolate Doom on Debian](/Building_Chocolate_Doom_on_Debian.md) - also applies to Ubuntu and other distributions based on Debian.
- [Building Chocolate Doom on Fedora](/Building_Chocolate_Doom_on_Fedora.md)
- [Building Chocolate Doom on Gentoo](/Building_Chocolate_Doom_on_Gentoo.md)

If your distribution is not in the above list, you can try the [generic install instructions](/Building_Chocolate_Doom_on_Linux_(generic).md) which should work under any distribution.

## Getting help {#getting_help}

If you have trouble in getting Chocolate Doom to work, feel free to [join the official Discord guild](https://discord.gg/fsVZfEE), there are experienced Linux users there who are willing and able to help with any issues that you might come across.
