Building Chocolate Doom on Linux is fairly straightforward.  However, the process for doing so depends on the Linux distribution that you are using.

Here are some instructions for building under common distributions:

* [[Building Chocolate Doom on Debian]] - also applies to Ubuntu and other distributions based on Debian.
* [[Building Chocolate Doom on Fedora]]
* [[Building Chocolate Doom on Gentoo]]

If your distribution is not in the above list, you can try the [[Building Chocolate Doom on Linux (generic)|generic install instructions]] which should work under any distribution.

== Getting help ==

If you have trouble in getting Chocolate Doom to work, feel free to join the [irc://irc.oftc.net/chocolate-doom Chocolate Doom IRC channel] (irc.oftc.net #chocolate-doom) to ask for help.  There are several experienced Linux users in this channel who will be able to help out.

== Common problems ==

; MIDI music / lockups : Linux's native MIDI output is poor and can cause the game to lock up.  You can work around this by disabling music output in chocolate-setup.  It's possible to get decent MIDI output by installing Timidity.
