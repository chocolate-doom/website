This page is intended to be a list of recommended [[doom:Vanilla Doom|vanilla-compatible]] gameplay enhancement mods with similar philosophies to Chocolate Doom.

== Doom Minor Sprite Fixing Project ==

The Sprite Fixing Project provides minor adjustments to fix issues with some of Doom's sprites, such as:

* Fixes for single-pixel graphical errors
* Adjustment of sprite offsets to improve animation of certain monsters
* Addition of extra rotation angles for zombie monsters which were omitted from the official IWADs.

== Perkristian hi-res Doom sound pack ==

The hi-res sound pack contains remastered versions of the Doom sound effects which have been remade at higher sampling rates (Doom's original sound effects were sampled at 11025Hz, which is considered fairly low-quality nowadays).

=== External links ===

* [http://www.perkristian.net/game_doom-sfx.shtml Website with more information] including download.
* [https://www.doomworld.com/vb/wads-mods/45117-high-quality-original-doom-sfx-updated-01-08-10/ First] and [https://www.doomworld.com/vb/wads-mods/58879-the-hi-res-doom-sound-pack-is-updated/ second] Doomworld threads about the mod.

== Roland SC-55 music packs ==

These downloadable music packs contain high quality recordings of Doom's music played through a [[wikipedia:Roland SC-55|Roland SC-55]], the MIDI synthesizer used by [[doom:Robert_Prince|Bobby Prince]] when composing Doom's music. Usable with Chocolate Doom's [[digital music packs]] feature.

=== External links ===

* [http://sc55.duke4.net/ Website] with downloads for the music packs.

== EAWPATS sound font ==

There are a wide variety of options available for music playback with Chocolate Doom. One good option is to use [[wikipedia:TiMidity++|Timidity]], and the EAWPATS patch set makes for a good time-tested starter set.

=== External links ===

* {{idgames|file=sounds/eawpats|title=EAWPATS}} on the idgames archive.

== DMXOPL ==
{{idgames|DMXOPL}}
If you're more of a fan of chiptune-style music, [[doom:DMXOPL|DMXOPL]] provides a replacement set of OPL instrument patches that can be used with Chocolate Doom's [[OPL MIDI]] playback.
