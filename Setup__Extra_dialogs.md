This page documents a couple of other common dialog windows found in the [Setup](/Setup.md) tool.

## Extra command line parameters {#extra_command_line_parameters}

{% image filename:Extra_Command_Line_Parameters.png width:300 %}
{% endimage %}

This window is in common with the multiplayer and level warp windows. It allows appending additional command line parameters that are not available via Setup\'s normal menus. Each option and its argument should appear in just one line, for example \"-deh batman.deh\".

## Add WADs {#add_wads}

{% image filename:Add_WADs.png width:300 %}
{% endimage %}

This window is also in common with the multiplayer and level warp windows. You can use it to enter a path to additional WADs to load. This is equivalent to passing \"-file level.wad\" on the command line, or using -file in the extra command line parameters window.
