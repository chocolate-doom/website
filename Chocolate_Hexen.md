'''Chocolate Hexen''' is a port of the [[wikipedia:Hexen|Hexen]] source code to the Chocolate Doom codebase. The aim is to develop a Hexen source port that includes the [[:Category:Features|features]] of Chocolate Doom.

Development of Chocolate Hexen is taking place on [[Raven-branch]].  It is not yet complete, although the game is playable in single player mode.  When finished, it will be part of the mainline Chocolate Doom code.
