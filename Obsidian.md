Obsidian is a source port and a fork of Chocolate Doom by tm512 that aims to be a "thin server" multiplayer port. It puts in new features that don't deviate too far from classic Doom, however, it is still in early development and it will lily stay like that for the saleable future as the last time the port was updated was in 2011.

You can join up to the port's IRC at #obsidian on irc.oftc.net if you have any questions, however, seeing that the port has not been updated in a long time, it is questionable if anyone will be there.
